## Bottom Line

The codebase still has the same structural debt, **plus a new credential leak**. The top things to fix right now:

1. **Rotate the Supabase anon key** and remove it from `config.js`.
2. **Remove or replace `sw.js`** — stop loading the external `3nbf4` service worker.
3. **Delete dead files**: `arena-core.js`, `arena-redesign.css`, `build-deploy.js`, `old-html-backup/`, `next-dualmind/`, `deploy_build/`, nested duplicate pages.
4. **Load `tokens.css` and `Outfit` font** on every standalone HTML page.
5. **Unify the toggle-response button** — use only `ChatView.js`’s class-based one and drop the inline-styled `app.js` version.
