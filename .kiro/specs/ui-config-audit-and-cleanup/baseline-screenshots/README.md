# Baseline Screenshots Directory

This directory contains baseline screenshots captured before CSS consolidation.

## Status

**⚠️ MANUAL TASK REQUIRED**

Screenshots need to be captured manually or via automated script. See `../baseline-screenshots-guide.md` for detailed instructions.

## Directory Structure

- `320px/` - Extra small mobile screenshots
- `380px/` - Small mobile screenshots
- `560px/` - Medium mobile screenshots
- `640px/` - Large mobile screenshots
- `768px/` - Tablet screenshots
- `1024px/` - Small desktop screenshots
- `1440px/` - Desktop screenshots
- `1920px/` - Large desktop screenshots

## Expected Files Per Breakpoint

Each breakpoint folder should contain approximately 12 screenshots covering:
1. Empty state
2. Sidebar states (open/collapsed/closed)
3. Chat with messages
4. Response cards (various states)
5. Voting UI
6. Modals
7. Dropdowns
8. Header states
9. Input states
10. Model selector
11. Hover states
12. Focus states
