# src/app/routes

Thin route modules, one per URL, named after the URL (`design.tsx` for `/design/`).

**Belongs here:** the route's `meta` (title, description, robots, canonical), `links`, loaders when a route is prerendered, and a default export that renders one feature's page component.

**Rules**

- No UI or logic of their own: compose features (`@/features/<name>`) and nothing else.
- Default export required (React Router loads it); everything else is a named export.
- Route types come from `./+types/<route>`, generated by `react-router typegen` (part of `npm run typecheck`).
