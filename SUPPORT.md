## Something is broken or missing

- **Bugs**: open a [bug report](https://github.com/dualmindlabs/DualMind_UI/issues/new?template=bug_report.yml).
- **Ideas and feature requests**: open a [feature request](https://github.com/dualmindlabs/DualMind_UI/issues/new?template=feature_request.yml).
- Search [existing issues](https://github.com/dualmindlabs/DualMind_UI/issues) first; adding details to an existing issue is more helpful than a duplicate.
- To check whether the API is up, open [api.dualmindlab.tech/health](https://api.dualmindlab.tech/health).

## Account and other questions

Email [support@dualmindlab.tech](mailto:support@dualmindlab.tech) for account problems, model suggestions or anything that does not fit an issue. Never send passwords or tokens by email.

## Security

Do not report vulnerabilities in public issues. See [SECURITY.md](./SECURITY.md).
